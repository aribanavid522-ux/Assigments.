FOOD CORNER - 5 PAGE RESTAURANT WEBSITE
========================================

PROJECT FILES
-------------
index.html       Home page
pizza.html       Pizza menu (6 products)
burger.html      Burger menu (6 products)
sandwich.html    Sandwich menu (6 products)
desserts.html    Desserts menu (6 products)
style.css        Shared design and responsive styling
script.js        Cart, mobile menu and contact form interactions
images/          Folder reserved for your own downloaded images

HOW TO RUN IN VS CODE
---------------------
1. Download and extract food_corner.zip.
2. Open Visual Studio Code.
3. Select File > Open Folder.
4. Choose the extracted "food_corner" folder.
5. Open index.html.
6. Right-click in the editor and choose "Open with Live Server".
7. Use the navbar to visit all five pages.

If Live Server is not installed:
- Open Extensions in VS Code.
- Search for "Live Server".
- Install it, then repeat step 6.

FEATURES
--------
- Five separate HTML pages.
- Shared navbar and footer.
- Responsive layout for desktop, tablet and mobile.
- Four clickable food categories on the home page.
- Six products on each food category page.
- Add-to-cart buttons.
- Cart counter, remove item and automatic total.
- Cart is saved in the browser with localStorage.
- Basic contact form validation and demo success message.

IMPORTANT
---------
Food photos are loaded from Unsplash image URLs, so internet access is
needed to display them. The images/ folder is included so you can add
your own downloaded images later.

This is a frontend portfolio/demo project. The cart and contact form
do not connect to a real restaurant, payment system or backend.
